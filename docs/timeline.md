# 결정의 흐름

PickEatUp이 작은 MVP에서 지금 모습이 되기까지 내린 결정을 시간 순서로 정리했습니다. 시각은 한국 시간이고, 비공개 저장소의 병합(=배포) 시각입니다. main 브랜치에 병합되면 바로 배포되므로, 아래 항목은 모두 **구현 · 병합 · 배포**까지 된 상태입니다. 사용자 확인 여부는 따로 적었습니다.

각 단계의 판단 이유는 [개선 사례](README.md#주요-기록-주제)에 자세히 있습니다.

## 1단계 · 메뉴 하나를 제안하는 MVP (10월 1일 ~ 2일 새벽)

| 시각 | 결정 | 왜 |
| --- | --- | --- |
| 10/1 22:42 | **첫 MVP**: 취향 4가지(나라·맛·양·종류)를 고르면 구체적인 메뉴 하나를 제안하고, 함께 먹을 사람 중 결정권자를 뽑는다 | "오늘 뭐 먹지?"에서 가장 힘든 건 후보를 떠올리는 일이라, 범주가 아니라 *순대국밥* 같은 메뉴 하나를 내밀기로 함 |
| 10/2 00:00 ~ 00:42 | '고민 없이 바로 골라줘'를 맨 위로, '아무거나'를 질문마다, 노트북 한 화면에 맞추기, 휴대폰에서는 결과를 별도 화면으로 | 조건을 고르지 않고도 시작할 수 있어야 하고, 고르는 화면과 결과가 한 화면에 들어와야 함 |
| 10/2 01:09 | 휴대폰에서 '아무거나'를 질문 제목 옆으로, '다시 뽑기'를 큰 버튼으로 | 갤럭시(360px)에서 네 번째 질문이 화면 밖으로 밀림 |
| 10/2 01:20 | 결정권자 화면 여백을 줄여 뽑기 버튼을 첫 화면 안으로 | 세 명을 입력하면 버튼이 잘림 |
| 10/2 02:17 | **메뉴 50개 → 130개**, '다른 거 추천'은 이미 보여준 메뉴를 기억해서 겹치지 않게 | 직전 메뉴 하나만 빼면 두 메뉴 사이를 왕복함 |
| 10/2 02:26 | 이모지가 없는 한식(김밥·떡볶이·국밥·찜)에 대표 그림 | 비슷한 이모지로는 메뉴가 바로 떠오르지 않음 |
| 10/2 02:42 | 방문 통계(Vercel Web Analytics) 연결 | 쿠키 없이 페이지 조회만 보는 방식이라 개인정보 부담이 적다고 판단 |
| 10/2 03:13 | **나라는 고정, 나머지 조건은 우선순위대로** 내려가며 추천 | 일식을 골랐는데 크림 파스타·마라탕이 나옴 |

## 2단계 · 여럿이 겪는 다른 결정들 (10월 3일 오전 ~ 오후)

| 시각 | 결정 | 왜 |
| --- | --- | --- |
| 10/3 11:16 | **점심 회식 → 근처 식당 후보**: 나라와 밥/면/고기 두 가지만 고르면 걸어갈 만한 식당 3~5곳 | 여럿이 먹을 때 힘든 건 "어디 갈래?"를 떠올리고 눈치 보며 제안하는 일. 합의할 단위는 메뉴보다 넓은 '매장 유형' |
| 10/3 11:33 | **오늘 어디서 만나?**: 서울 거점 23곳 중 하나를 제안, 후보 지도 | 각자 다른 곳에서 올 때 첫 제안을 대신하기 |
| 10/3 12:23 | **메뉴 구조 정리**: '오늘 뭐 먹지?'가 메인, 여럿이 쓰는 기능은 작은 '여럿이라면' 아래로. 위치는 필요할 때 묻고 언제든 바꾸기 | 상단에 기능 네 개가 나란히 있어 메인이 흐려짐. '혼자/여럿이'를 묻는 건 모두에게 선택을 하나 더 늘림 |
| 10/3 13:08 | 공통 푸터, 만든 사람 소개, 로그인 없는 한마디 보드 | 누가 만들었는지 밝히고, 반응과 후보 추가 요청을 부담 없이 받기 |
| 10/3 13:27 | **식당: 둘러보고 → 고르고 → 정하고 → 공유하고 → 기억하기** | 후보를 본 다음 단계가 비어 있었음. 정한 곳은 다들 스크린샷을 안 찍어서 흩어짐 |
| 10/3 14:15 ~ 15:04 | 데스크톱 작은 글씨 키우기 + 글자 크기 3단계 버튼, 모든 화면에 같은 푸터 | 노트북에서 작은 안내 글씨가 잘 안 읽힘 |
| 10/3 15:46 | 혼자 고른 메뉴도 '최근에 고른 메뉴' 5개로 | 식당과 같은 규칙("정한 것만 남는다")으로 맞추기 |

## 확인한 범위

- 모든 항목은 자동 테스트(단위·브라우저)와 휴대폰·데스크톱 크기 화면 확인을 거쳐 병합했습니다. 이건 **동작 검증**이고, 사용자 가치가 검증됐다는 뜻은 아닙니다.
- 실제 휴대폰으로 확인한 것:
  - **확인됨:** 갤럭시에서 이미지 공유(카톡에 그림만 감)와 갤러리 저장
  - **아직 확인 못 함:** 아이폰 공유 창 동작
- 사용자 반응은 제작자 본인의 사용과 소수 지인의 반응 수준입니다.
