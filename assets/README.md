| 파일 | 내용 | 촬영 조건 |
| --- | --- | --- |
| `app-icon.png` | 배포 중인 PICK 말풍선 앱 아이콘 | 앱에서 제공하는 512×512 PNG 원본 |
| `menu-mobile.png` | 모바일 첫 화면의 취향 선택 | Chromium, 390×780 CSS px, 모바일 에뮬레이션 |

새 브라우저 세션에서 촬영했으며 개인의 기존 기록이나 위치는 사용하지 않았습니다. 결과 메뉴는 실제 추첨으로 나온 예시이고, 모바일과 데스크톱의 추첨은 서로 독립적입니다. 모바일 이미지는 설치된 네이티브 앱이나 실제 기기의 사진이 아닌 반응형 웹 화면입니다.

화면과 아이콘이 변경되면 배포 상태를 확인해 이미지를 교체하고, 이 문서의 촬영 시점·조건과 README의 대체 텍스트도 함께 갱신합니다.
